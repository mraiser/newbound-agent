Noobscape v2 Builder

Build a chrome-privileged Firefox fork — the browser agent.browser drives — from source, patch in the v2 file-RPC mechanism, and install it where agent.browser looks.

1 · Configuration

The install path is a config option, so the build can live anywhere and still be found. NOOBSCAPE_BIN defaults to /noobscape/bin/firefox, and agent.browser reads it.

2 · Build pipeline

Run the steps in order. Download → extract → deps → build are long (30 min–hours, background); the log below streams while they run.

  1. Materialize kit
  2. Download & extract source
  3. Patch (v2 nsDocShell mechanism)
  4. Install build deps (mach bootstrap)
  5. Build Firefox
Mechanism updated? After a new nsDocShell_v2_block.cpp lands, Patch alone is a no-op on an already-patched tree. This restores the pristine source, applies the current block, and runs an incremental build (minutes). Then install below.

3 · Install

Point NOOBSCAPE_BIN at the built browser. Symlink is the light default; copy clones the whole dist/bin so it survives cleaning the workspace. Close any open agent.browser session first so it picks up the new libxul.
